# אימות CI לענף תוכנית הלימודים

הענף נוצר מנקודת הקוד של PR #78 לאחר הוספת קטלוג המקצועות, מסכי היחידות, השיעורים ובדיקותיהם.

הקובץ נועד להפעיל את תהליך GitHub Actions הקיים, אשר מריץ:
- npm install
- npm test
- npm run build

אין בקובץ זה שינוי קוד יישומי. לאחר קבלת תוצאות CI יש להשוות את קוד המקור לענף PR #78 ולתעד את ה-SHA שנבדק.
