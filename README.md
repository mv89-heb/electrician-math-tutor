# Electrician Math Tutor

מערכת WEB אינטראקטיבית לתרגול מתמטיקה לקראת לימודי חשמלאי מוסמך.

## עקרונות
- תרגיל אחד בכל פעם.
- קושי הדרגתי.
- לא חושפים פתרון מיד.
- רמזים מדורגים.
- חיבור בין מתמטיקה לעולם החשמל.
- מעקב שליטה לפי נושא.

## הרצה
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm start
```

הגרסה הראשונה היא MVP ללא תלות ב-API חיצוני. שכבת AI יכולה להתווסף בהמשך בלי לשנות את מנגנון הלמידה המרכזי.
